## 🚀 機能

- 🔢 **累積トークンカウンター** – 現在の会話のすべてのメッセージのトークンを合計します（`o200k_base` トークナイザーに基づく推定）。合計は `sessionStorage` に保存されるため、ページをリロードしてもリセットされません。
- 🎯 **グラデーションバーと白いドット** – バーは固定のグラデーション（緑 → 赤）を持ち、**白いドット** が移動して使用率（参考上限 200,000 トークン）を示します。
- ⏳ **キャッシュタイマー** – 会話がキャッシュに残る時間を表示します（アシスタントの最後の応答から5分間）。キャッシュされたメッセージは安価で高速です。
- 🌗 **テーマ自動適応** – システムのライトテーマまたはダークテーマに合わせてカウンターの色が変わります（テキスト色、ツールチップの背景など）。
- 📌 **固定位置** – カウンターは**右上隅**に配置され（距離調整可能）、UIボタンに重なりません。
- 🔄 **リアルタイム更新** – メッセージを送受信するたびにカウンターが即座に更新されます。

## 🤔 DeepSeek でのトークン計算方法

他の言語モデルと同様に、DeepSeek はテキストを**トークン**（単語、単語の一部、特殊文字など）に分割します。トークン数は計算コストとコンテキストウィンドウの使用に直接影響します。

### 📊 コンテキスト上限（参考値）

- DeepSeek の最大コンテキストは **100万トークン** (1,000,000) です。
- ただし、この拡張機能で使用しているトークナイザー (`o200k_base`) は元々 OpenAI モデル用に設計されたものであり、**DeepSeek のネイティブなトークナイズと完全には一致しません**。
- そのため、**200,000トークンを参考上限**（視覚的なバーのスケールのみ）として使用しています。数値カウントはあくまで**概算**であり、消費量の目安として役立ちます。

### ⚙️ 拡張機能がトークンをカウントする方法

1. **メッセージの抽出** – `content.js` スクリプトは、安定した CSS クラス (`.ds-message`, `.fbb737a4` など) を使用して、あなたとアシスタントが送信した各テキストブロックを識別します。
2. **トークナイズ** – 新しいメッセージはそれぞれ `o200k_base.js` トークナイザーによって処理され、おおよそのトークン数を返します。
3. **累積** – 現在の会話のすべてのメッセージのトークンが合計され、`sessionStorage` に保存されます。ページをリロードしても累計は失われません。
4. **リアルタイム更新** – メッセージが送受信されるたびに、カウンターは自動的に更新されます（`MutationObserver` と `setInterval` を使用）。

### 📈 グラデーションバーと白いドットの見方

- **グラデーションバー** は参考上限（200,000トークン）に対する **0% から 100%** のスケールを表します。  
  - 開始時は **緑** (0%) → 終了時は **赤** (100%)。
- **白いドット** はバー上を移動し、現在の会話で既に使用されたトークンの正確な割合を示します。
- バーの下には**絶対トークン数**が表示されます（例: `~61,332 トークン`）。

### ⏱️ キャッシュタイマー

- アシスタントが応答するたびに、**5分間のタイマー** が開始されます。  
- この期間中、会話は「キャッシュ済み」と見なされ、以降のやり取りは高速かつ低コストになるはずです。  
- カウンターはキャッシュの期限が切れるまでの残り時間を正確に表示します。

## 🛠️ インストール方法

### Chrome / Edge / その他の Chromium ブラウザ

1. **拡張機能のファイルをダウンロード**（このリポジトリをクローンするか、ZIPをダウンロードしてフォルダに解凍してください）。
2. `chrome://extensions`（または `edge://extensions`）にアクセスします。
3. **デベロッパーモード** をオンにします（右上のトグルスイッチ）。
4. **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
5. 拡張機能のファイルを保存した**フォルダ**を選択します。
6. 完了です！拡張機能が一覧に表示されます。`chat.deepseek.com` にアクセスして、カウンターが動作するのを確認してください。

### Firefox（一時的なインストール）

1. `about:debugging` にアクセスします。
2. **「この Firefox」** をクリックします。
3. **「一時的なアドオンを読み込む」** をクリックします。
4. 拡張機能フォルダ内の任意のファイル（例: `manifest.json`）を選択します。
5. 拡張機能が読み込まれます。永続的に使用するには、拡張機能に署名する必要があります。

## ⚙️ 仕組み（技術的な詳細）

- **`content.js`** – 安定したセレクタ (`.ds-message`, `.fbb737a4`) を使用して DeepSeek の DOM からメッセージを抽出します。新しいメッセージはトークナイズされ、トークンは `sessionStorage` に累積されます。
- **`ui.js`** – `position: fixed`、半透明の背景、グラデーションバー、白いドット、ライト/ダークテーマに適応するツールチップを備えた固定コンテナを `body` に注入します。
- **`o200k_base.js`** – トークナイザー (MIT) – 概算カウントのみに使用されます。このファイルのクレジットは全て [gpt-tokenizer](https://github.com/niieani/gpt-tokenizer) プロジェクトに帰属します。
- **更新** – `MutationObserver` が DOM の変更を監視し、`setInterval`（2秒ごと）がデータを最新に保ちます。

## 🔒 プライバシー

- ✅ すべてのデータはブラウザの **ローカル** に保存されます（`sessionStorage`）。
- ✅ 外部サーバーにデータが送信されることはありません。
- ✅ 拡張機能はドメイン `chat.deepseek.com` でのみコードを実行します。
- ✅ トラッキングやテレメトリは一切使用していません。
