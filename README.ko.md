# 🔢 DeepSeek Counter — 현대적인 토큰 카운터 (그라데이션 UI)

<p align="center">
  <img src="icons/deepseek.png" alt="DeepSeek 로고" width="200">

**DeepSeek Counter** 는 DeepSeek 인터페이스(`chat.deepseek.com`)에 실시간 토큰 카운터, 캐시 타이머 및 아름다운 그라데이션 바(초록 → 빨강)를 추가하는 브라우저 확장 프로그램입니다. 깔끔하고 시각적으로 매력적인 경험을 제공하기 위해 처음부터 개발되었습니다.

## 🚀 기능

- 🔢 **누적 토큰 카운터** – 현재 대화의 모든 메시지 토큰을 합산합니다(`o200k_base` 토크나이저 기반 추정). 총합은 `sessionStorage`에 저장되므로 페이지를 새로 고쳐도 초기화되지 않습니다.
- 🎯 **그라데이션 바와 흰색 점** – 바는 고정된 그라데이션(초록 → 빨강)을 가지며 **흰색 점**이 이동하여 사용 비율(참조 한도 200,000 토큰)을 표시합니다.
- ⏳ **캐시 타이머** – 대화가 캐시에 남아 있는 시간을 표시합니다(마지막 어시스턴트 응답으로부터 5분). 캐시된 메시지는 더 저렴하고 빠릅니다.
- 🌗 **테마 자동 적응** – 시스템의 라이트 또는 다크 테마에 맞춰 카운터의 색상이 변경됩니다(텍스트 색상, 툴팁 배경 등).
- 📌 **고정 위치** – 카운터는 **오른쪽 상단 모서리**에 위치하며(거리 조정 가능), UI 버튼과 겹치지 않습니다.
- 🔄 **실시간 업데이트** – 메시지를 보내거나 받을 때마다 카운터가 즉시 업데이트됩니다.

## 🤔 DeepSeek에서 토큰은 어떻게 계산되나요?

다른 언어 모델과 마찬가지로 DeepSeek은 텍스트를 **토큰**(단어, 단어의 일부 또는 특수 문자일 수 있는 단위)으로 분할합니다. 토큰 수는 계산 비용과 컨텍스트 창 사용에 직접적인 영향을 미칩니다.

### 📊 컨텍스트 한도 (참조)

- DeepSeek의 최대 컨텍스트는 **100만 토큰**(1,000,000)입니다.
- 그러나 이 확장 프로그램에서 사용하는 토크나이저(`o200k_base`)는 원래 OpenAI 모델용으로 설계되었으며 **DeepSeek의 기본 토큰화와 정확히 일치하지 않습니다**.
- 따라서 **참조 한도로 200,000 토큰**을 사용합니다(시각적 바 스케일만 해당). 숫자 카운트는 여전히 **근사치**이며 소비량을 파악하는 데 유용합니다.

### ⚙️ 확장 프로그램이 토큰을 계산하는 방법

1. **메시지 추출** – `content.js` 스크립트는 안정적인 CSS 클래스(`.ds-message`, `.fbb737a4` 등)를 사용하여 사용자와 어시스턴트가 보낸 각 텍스트 블록을 식별합니다.
2. **토큰화** – 각 새 메시지는 `o200k_base.js` 토크나이저에 의해 처리되어 대략적인 토큰 수를 반환합니다.
3. **누적** – 현재 대화의 모든 메시지 토큰이 합산되어 `sessionStorage`에 저장됩니다. 페이지를 새로 고쳐도 누적 합계가 손실되지 않습니다.
4. **실시간 업데이트** – 메시지를 보내거나 받을 때마다 카운터가 자동으로 업데이트됩니다(`MutationObserver` 및 `setInterval` 사용).

### 📈 그라데이션 바와 흰색 점 이해하기

- **그라데이션 바**는 참조 한도(200,000 토큰)에 대한 **0%에서 100%** 스케일을 나타냅니다.  
  - 시작은 **초록색**(0%) → 끝은 **빨간색**(100%).
- **흰색 점**은 바를 따라 이동하며 현재 대화에서 이미 사용된 토큰의 정확한 비율을 보여줍니다.
- 바 아래에는 **절대 토큰 수**가 표시됩니다(예: `~61,332 토큰`).

### ⏱️ 캐시 타이머

- 어시스턴트가 응답할 때마다 **5분 타이머**가 시작됩니다.  
- 이 기간 동안 대화는 "캐시됨"으로 간주되며, 이후 상호 작용은 더 빠르고 저렴해야 합니다.  
- 카운터는 캐시 만료까지 남은 시간을 정확히 표시합니다.

## 🛠️ 설치 방법

### Chrome / Edge / 기타 Chromium 브라우저

1. **확장 프로그램 파일 다운로드** (이 저장소를 클론하거나 ZIP을 다운로드하여 폴더에 압축 해제).
2. `chrome://extensions`(또는 `edge://extensions`)로 이동합니다.
3. **개발자 모드**를 켭니다(오른쪽 상단 토글 스위치).
4. **"압축 해제된 확장 프로그램 로드"** 를 클릭합니다.
5. 확장 프로그램 파일을 저장한 **폴더**를 선택합니다.
6. 완료! 확장 프로그램이 목록에 나타납니다. 이제 `chat.deepseek.com`으로 이동하여 카운터가 작동하는지 확인하세요.

### Firefox (임시 설치)

1. `about:debugging`으로 이동합니다.
2. **"이 Firefox"** 를 클릭합니다.
3. **"임시 애드온 로드"** 를 클릭합니다.
4. 확장 프로그램 폴더 내의 아무 파일(예: `manifest.json`)을 선택합니다.
5. 확장 프로그램이 로드됩니다. 영구적으로 사용하려면 확장 프로그램에 서명해야 합니다.

## ⚙️ 작동 방식 (기술적 세부 사항)

- **`content.js`** – 안정적인 선택자(`.ds-message`, `.fbb737a4`)를 사용하여 DeepSeek의 DOM에서 메시지를 추출합니다. 새 메시지는 토큰화되고 토큰은 `sessionStorage`에 누적됩니다.
- **`ui.js`** – `position: fixed`, 반투명 배경, 그라데이션 바, 흰색 점, 라이트/다크 테마에 적응하는 툴팁을 갖춘 고정 컨테이너를 `body`에 삽입합니다.
- **`o200k_base.js`** – 토크나이저 (MIT) – 근사치 계산에만 사용됩니다. 이 파일의 모든 크레딧은 [gpt-tokenizer](https://github.com/niieani/gpt-tokenizer) 프로젝트에 있습니다.
- **업데이트** – `MutationObserver`가 DOM 변경을 감시하고 `setInterval`(2초마다)이 데이터를 최신 상태로 유지합니다.

## 🔒 개인정보 보호

- ✅ 모든 데이터는 브라우저의 **로컬**에 저장됩니다(`sessionStorage`).
- ✅ 외부 서버로 데이터가 전송되지 않습니다.
- ✅ 확장 프로그램은 도메인 `chat.deepseek.com`에서만 코드를 실행합니다.
- ✅ 추적이나 텔레메트리는 전혀 사용하지 않습니다.
