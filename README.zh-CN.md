## 🚀 功能特性

- 🔢 **累计令牌计数** – 累加当前对话中所有消息的令牌数（基于 `o200k_base` 分词器估算）。总数存储在 `sessionStorage` 中，刷新页面不会丢失。
- 🎯 **渐变条与白点** – 固定渐变条（绿 → 红），**白点** 移动指示已使用百分比（参考限制 200,000 令牌）。
- ⏳ **缓存计时器** – 显示对话还将缓存多久（从助手最后回复起 5 分钟）。缓存消息更便宜且更快。
- 🌗 **自动适应主题** – 计数器自动适配系统亮色或暗色主题（文本颜色、工具提示背景等）。
- 📌 **固定位置** – 计数器位于**右上角**（距离可调），不覆盖任何界面按钮。
- 🔄 **实时更新** – 每次发送或接收新消息，计数器都会立即更新。

## 🤔 DeepSeek 中如何计算令牌？

与其他语言模型一样，DeepSeek 将文本分割成 **令牌** —— 可以是单词、单词的一部分或特殊字符。令牌数量直接影响计算成本和上下文窗口的使用。

### 📊 上下文限制（参考）

- DeepSeek 最大上下文为 **1 百万令牌**（1,000,000）。
- 但本扩展使用的分词器 (`o200k_base`) 最初是为 OpenAI 模型设计的，**不完全匹配 DeepSeek 的原生分词**。
- 因此我们使用 **200,000 令牌作为参考限制**（仅用于条形图视觉比例）。数字计数仍是**近似估计**，有助于了解消耗情况。

### ⚙️ 扩展如何计数令牌

1. **消息提取** – `content.js` 脚本通过稳定的 CSS 类 (`.ds-message`, `.fbb737a4` 等) 识别你发送和助手回复的文本块。
2. **分词** – 每条新消息由 `o200k_base.js` 分词器处理，返回一个近似令牌数。
3. **累计** – 当前对话中所有消息的令牌数相加并存储在 `sessionStorage` 中。即使刷新页面，累计总数也不会丢失。
4. **实时更新** – 每当发送或接收新消息，计数器自动更新（使用 `MutationObserver` 和 `setInterval`）。

### 📈 理解渐变条和白点

- **渐变条** 表示参考限制 (200,000 令牌) 从 **0% 到 100%** 的刻度。  
  - 开始为 **绿色** (0%) → 结束为 **红色** (100%)。
- **白点** 在条上移动，准确显示当前对话已使用的令牌百分比。
- 条下方显示**绝对令牌计数**（例如 `~61,332 令牌`）。

### ⏱️ 缓存计时器

- 每当助手回复时，启动 **5 分钟计时器**。  
- 在此期间，对话被视为“已缓存”，后续交互应该更快且更便宜。  
- 计数器准确显示缓存剩余时间。

## 🛠️ 安装

### Chrome / Edge / 其他 Chromium 浏览器

1. **下载扩展文件**（克隆此仓库或下载 ZIP 并解压到文件夹）。
2. 打开 `chrome://extensions`（或 `edge://extensions`）。
3. 开启**开发者模式**（右上角开关）。
4. 点击**“加载已解压的扩展”**。
5. 选择保存扩展文件的**文件夹**。
6. 完成！扩展将出现在列表中。现在访问 `chat.deepseek.com` 即可看到计数器工作。

### Firefox（临时安装）

1. 打开 `about:debugging`。
2. 点击**“此 Firefox”**。
3. 点击**“临时加载扩展”**。
4. 选择扩展文件夹内的任意文件（例如 `manifest.json`）。
5. 扩展将被加载。要永久使用，需对扩展进行签名。

## ⚙️ 工作原理（技术细节）

- **`content.js`** – 使用稳定的选择器 (`.ds-message`, `.fbb737a4`) 从 DeepSeek 的 DOM 中提取消息。每条新消息被分词，令牌累加到 `sessionStorage`。
- **`ui.js`** – 在 `body` 中注入固定容器，使用 `position: fixed`、半透明背景、渐变条、白点和适应亮/暗主题的工具提示。
- **`o200k_base.js`** – 分词器 (MIT) – 仅用于近似计数。该文件的所有荣誉属于 [gpt-tokenizer](https://github.com/niieani/gpt-tokenizer) 项目。
- **更新机制** – `MutationObserver` 监听 DOM 变化，`setInterval`（每 2 秒）保持数据新鲜。
